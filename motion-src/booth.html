◆About

To celebrate the release of the new Photo Booth feature on VRoid Hub and the new animation format (.vrma), we will be giving out 7 types of VRM animations for free. VRM animation files downloaded from this page can be used in VRoid Hub's Photo Booth and linked apps. Please make sure to check the terms of use before using them for taking photos/videos, as well as for operational checks and testing! ▼Learn more https://vroid.com/en/news/6HozzBIV0KkcKf9dc1fZGW
